# Week 04 Activity 01

## Project Description
This project applies Python to computational mathematical modeling through four activities: descriptive statistics, linear algebra, polynomial operations, and student performance analysis.

## Activities

### Question 1: Study-Hour Statistics
Calculate the mean, median, sample variance, and sample standard deviation for study-hour data. Update the calculations after correcting a recorded value, then plot a histogram.

### Question 2: Linear Algebra
Create a coefficient matrix and calculate its determinant, inverse, eigenvalues, and eigenvectors. Solve the linear system and check the residual and its Euclidean norm.

### Question 3: Polynomial Operations
Find the polynomial’s roots, calculate its first and second derivatives, determine its indefinite integral, and evaluate a definite integral.

### Question 4: Student Performance
Load the student data into a DataFrame. Summarize exam marks, identify the highest mark, calculate the correlation between study hours and exam marks, group exam results into categories, export the results, and create plots.

## Setup Instructions
1. Install Python.
2. Open a terminal in the project folder.
3. Create a virtual environment:
   `py -m venv .venv`
4. Install the required packages:
   `.\.venv\Scripts\python.exe -m pip install numpy pandas matplotlib streamlit`

## Execution Steps
Open the project folder in PyCharm and run the Python files for Questions 1–4.

For Question 4, keep `student_performance (1).csv` in the project folder, or update the file path in the code.
